# Arch Dotfiles

My arch system that focuses on providing a functional and performance oriented desktop experience with minimal setup and a mouse / touchpad free experience ( for the most part )

```
git clone https://github.com/Almighty42/Arch-Dotfiles.git
```

## Stack
- WM - awesomeWM
- Cat replacement - bat
- Notifications - dunst
- Terminal welcome screen - fastfetch
- Video player - mpv
- IDE - nvim
- Status bar - polybar
- Browser - qutebrowser
- File browser - ranger
- Dynamic menus - rofi
- + Many custom scripts!

## Scripts
- Tmux scripts ( fzf-based interactive menu for opening tmuxp sessions )
- System scripts ( theme changing and other scripts )
- Qutebrowser scripts ( yt to mpv pipe script )
- Programming scripts
- Kindle scripts ( syncing via SSH on a jailbroken kindle )
- Github scripts
- Download scripts
